# 연세 iPrint Native 0.1.15

M1 이상 Mac · macOS 15 이상 · 연세대 캠퍼스 네트워크에서 사용합니다.

## 설치

DMG를 열고 ‘연세 iPrint Native (비공식).app’을 Applications 폴더로 드래그합니다.
공증 DMG로 배포된 버전은 Developer ID 서명·Apple 공증을 적용했습니다. 소스로 직접 빌드한 ad-hoc 앱에는 공증이 적용되지 않습니다.

## 인쇄

1. 아이프린트 계정으로 로그인합니다. 로그인하면 같은 버튼이 ‘로그아웃’으로 바뀝니다.
2. ‘PDF 선택…’으로 인쇄할 문서를 선택합니다. 첫 장 썸네일로 문서를 확인합니다.
3. 단면·양면(긴 쪽/짧은 쪽 넘김)과 부수(1~99부)를 확인하고 ‘인쇄 보내기’를 누릅니다. 변환·압축·서버 전송이 자동으로 이어집니다.
4. ‘전송 완료’가 표시되면 복합기에서 로그인해 대기 문서를 선택하고 출력합니다.

A4 · 흑백으로 보냅니다. 기본값은 단면 · 1부이며, 문서 블록에서 변경할 수 있습니다.
양면의 긴 쪽 넘김은 책처럼, 짧은 쪽 넘김은 달력처럼 넘기는 방식입니다.
글자 간격 유지를 위해 외곽선 변환을 적용합니다.
부수는 문서 전체를 몇 벌 출력할지 지정하며, 전체 페이지 수×부수는 32,767 이하여야 합니다.
전송 중과 전송 완료 상태에서는 설정을 변경할 수 없습니다. 새 작업은 PDF를 다시 선택하세요.
현재 Samsung M4370/5370용이며, 이 모델은 흑백 전용입니다.
전송 완료 후 같은 PDF를 다시 보내려면 ‘PDF 선택…’으로 다시 선택합니다.
전송 결과가 불확실하다는 오류가 뜨면, 복합기 대기목록을 먼저 확인한 뒤 재시도하세요.

## 계정

‘새 회원가입…’에서 새 ID·이름·비밀번호·연락처·이메일을 직접 입력합니다.
ID와 비밀번호는 5~20자이며, 이름은 한글을 지원합니다(최대 20바이트, 한글 10자).
연락처는 하이픈 없이 숫자로 입력합니다. 약관·개인정보 안내를 확인하고 동의하면
‘동의하고 가입’을 누릅니다. 가입 후 로그인과 이름 조회 결과를 자동 확인합니다.
가입 여부가 불확실하면 가입을 반복하지 말고 새 ID로 로그인해 먼저 확인하세요.

로그인 뒤 ‘회원 정보 확인’에서 ID·이름·연락처·이메일을 조회할 수 있습니다.
모든 항목은 읽기 전용이며, 수정·저장 기능은 제공하지 않습니다.
현재 비밀번호 변경과 잔액 충전은 지원하지 않습니다.

## 문서와 비밀번호

원본 PDF는 변경하지 않습니다. 첫 장 미리보기는 Mac 안에서 생성하며 파일로 저장하지 않습니다. 임시 인쇄 문서는 전송 성공 또는 정상 종료 때 삭제합니다.
비정상 종료 때는 일부 임시 문서가 남을 수 있습니다.
임시 문서 위치: ~/Library/Application Support/Yonsei iPrint Native/Jobs/
비밀번호는 파일이나 키체인에 저장하지 않으며 로그아웃·종료 때 입력란을 비웁니다.

이전 버전에서 실제 가입·로그인·한글 이름 표시·흑백 PDF 출력을 확인했습니다.
현재 버전은 서버 대기 문서 조회·삭제를 지원합니다. 양면·여러 부수의 실제 출력·과금과 서버 대기 문서 조회·삭제는 2026-10-18 사용자가 현장 검증 완료를 확인했습니다.
앱 소스·Ghostscript 원본·수정 사항과 빌드 방법은 이 저장소에 있습니다.
설치 DMG를 공유할 때는 [0.1.15 전체 소스](https://github.com/jinh0park/yonsei-iprint-unofficial/tree/v0.1.15) 링크도 함께 안내해 주세요.


서버 대기 문서 (0.1.14 시험 기능)
- 로그인 후 왼쪽의 ‘서버 대기 문서…’를 누릅니다.
- 서버에 대기 중인 문서명·접수 시각·용지·페이지 수를 조회하고 새로고침할 수 있습니다.
- 삭제할 문서를 선택하고 ‘선택 문서 삭제…’를 누른 뒤 확인창에서 삭제를 확정합니다.
- 삭제 전 현재 목록을 확인하고, 삭제 후에도 다시 조회해 문서가 사라졌는지 확인합니다.
- Mac의 원본 PDF는 삭제하지 않습니다. 이미 출력 중인 문서는 취소되지 않을 수 있습니다.
- 오류나 불확실한 결과가 나오면 새로고침해 확인하세요. 자동으로 다시 삭제하지 않습니다.
- 실제 학교 서버의 조회·삭제는 2026-10-18 사용자가 현장 검증 완료를 확인했습니다.

0.1.14에서는 앱 이름과 창 제목에 ‘(비공식)’ 표시를 추가했습니다.


0.1.15 회원가입 진단
- 가입 실패 시 단계(R1~R4)·허용된 서버 상태 코드·실제 접속 서버 주소·앱 버전을 표시합니다.
- 단계 R2는 ID 사용 가능 확인, R4는 가입 정보 저장입니다. R4 오류는 일반적인 ID 중복 검사 오류와 다릅니다.
- ID·비밀번호·이름·연락처·이메일이나 임의의 서버 응답 전문을 표시·기록하지 않습니다. 허용 목록 밖의 응답은 가립니다. 진단 파일을 따로 저장하지 않습니다.
- 가입 저장을 요청한 뒤 결과가 불확실하면 자동 재시도하지 않습니다. 창을 닫고 방금 가입에 사용한 ID로 로그인해 먼저 확인하세요.
- 가입 요청 형식과 인쇄 기능은 변경하지 않았습니다. 다른 Mac의 가입 실패 원인은 아직 확인 중입니다.
